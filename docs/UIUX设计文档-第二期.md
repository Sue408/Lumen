# Lumen 二期视觉设计提案 —— 夜晚的档案室

> 依据：二期 GUI 视觉概念稿（Vellum / Antiquarian Library）。
> 定位：对《UIUX设计文档》（一期）**视觉层**的修订与扩展；页面结构、功能语义、数据口径不动。
> 冲突裁决：视觉样式（颜色 / 尺寸 / 圆角 / 卡片 / 图表外观）以本文件为准；功能、交互语义、文案纪律仍以一期文档为准。
> 日期：2026-10-17。

---

## 0. 一页摘要

- **一句话**：把一期的「白天账房」推进到「夜晚的档案室」——同一本账簿，换一副更冷、更静、更精确的面孔。
- **吸收概念稿的五件事**：近黑分层画布、面板容器、强对比排版（微标签 / 衬线大标题 / 大数字）、工具条语法、数据可视化成熟度（直线折线 + 端点聚焦 + 渐变面积）。
- **拒绝概念稿的四件事**：纯黑冷灰（保留暖调纸的血统）、12px+ 全屋大圆角（收敛为 12/8/4/pill 四档）、高饱和 SaaS 蓝（坚持矿物颜料，仅提亮）、装饰性彩块（微条改为真实数据）。
- **不改的事**：账簿隐喻、朱砂铁律、去脚手架图表、无 web 字体、`prefers-reduced-motion`、控件 28/32/40 三档、`tabular-nums` 铁律、无 CSS Modules、token 唯一来源。
- **改动面**：`theme.css`（值替换 + 新 token）、`layout.css`（骨架尺寸）、`base.css`（字阶）、全部 feature 样式（卡片化与工具条）、少量 TSX（微条、洞察卡位移）。

## 1. 概念稿解读

### 1.1 要素拆解

| 维度 | 概念稿的答案 |
| --- | --- |
| 画布 | 近黑（≈ `#0A0A0A`），全屏统一；侧栏与主区同底，靠 1px 线分隔 |
| 表面 | 卡片面 ≈ `#121212`～`#161616`，比画布亮一阶；描边 ≈ `#262626`；**无阴影** |
| 文本 | 白 `#FAFAFA` / 灰 `#A3A3A3` / 淡 `#6B6B6B` 三层；对比强烈 |
| 排版 | 微标签（11px 大写 + 宽字距）→ 衬线大标题（≈40px）→ 正文（13～15px）→ 注（12px）；层与层字族、字号、颜色同时变化 |
| 数字 | 大号、半粗、右对齐、等宽对齐（tabular）；值后面永远跟一行来源/上下文 |
| 形状 | 容器圆角 12～14px、控件 8px、pill 全圆；描边恒 1px；图标线性、stroke 细 |
| 组件 | 品牌块（徽标 + 名 + 副题）、分组导航（微标签 + 列表 + 彩点）、页头工具条、指标卡（标签 / 大数 / 注 / 底部微条）、图卡（标题 + 工具条 + 图）、边卡（环 + 键值 + 行列表） |
| 图表 | 直线段折线、单色面积渐隐、端点白点 + 虚线垂引、淡轴标签、无网格；环形图留缝、扇区可外扩 |
| 色彩 | chrome 全部黑白灰；颜色只出现在数据上（序列色、标识点），一处数据一种色 |

### 1.2 它为什么「像专业产品」——四条成因

1. **节奏一致性**：每张卡片都是同一乐句——微标签 → 标题 → 值 → 注。重复产生秩序感。
2. **材质单一**：所有容器同一种材质（面 + 1px 线 + 同圆角），没有任何异质元素（无阴影、无渐变、无插图、无花标题栏）。
3. **色彩纪律**：界面本身零彩色；彩色只标记数据身份。眼睛知道「有颜色 = 有信息」。
4. **工具条可预测**：所有控件收拢成右对齐的 pill 与图标按钮组，内容区只剩内容。

### 1.3 直接吸收 / 需要翻译 / 明确拒绝

| 处置 | 项目 |
| --- | --- |
| 直接吸收 | 近黑分层、1px 描边面板、微标签排版、衬线大标题、卡头图标徽章、指标卡四段式、工具条 pill + 图标组、端点聚焦图表、行列表右对齐数值 |
| 翻译为 Lumen 语义 | 彩点分类 → 对象标识点（供应商 / 模型，复用 `--brand-*`）；「ERAS + 年代」→ 不新造概念，导航保持六项；「Highlights 置顶卡」→ 不造功能（日志页「待处理」口径已覆盖）；促销卡 → 不学，侧栏底部仍为网关开关 |
| 明确拒绝 | 纯黑冷灰 `#0A0A0A`（改暖黑 `#141311`）；大圆角全家桶（收敛四档）；高饱和图表蓝（矿物靛青提亮代替）；卡片内嵌套小卡（改用行 + 发丝线）；指标卡装饰性方块虚线（换成真实数据微条） |

## 2. 设计理念（二期五原则）

### 原则一：近黑分层 —— 深色是主场

深色模式从「夜晚的纸」升级为精修主场：画布压深到暖黑 `#141311`，空间层级不再靠阴影，而靠**三级面 + 两级线**表达：

```
画布 paper → 面板 panel → 抬升面 panel-raised
线 line（发丝分隔） < 线 line-panel（面板描边） < 线 line-strong（选中/强调）
```

浅色主题同构存在（纸白 → 卡纸 → 纯白），两主题共享全部语义 token，不做分叉设计。

### 原则二：面板化 —— 分区即容器（修订一期「靠留白分区」）

分区单位从「留白 + 发丝线」改为**面板**：1px 描边 + 12px 圆角 + 20px 内边距。容器化不等于仪表盘化，纪律是：

1. 面板**永不嵌套**；面板内的次级分组用发丝线 + 间距，不再起卡。
2. 深色下面板无阴影；浅色下保留一期极淡纸层阴影（`--shadow-float` 不变）。
3. 面板头只有一行：**图标徽章 + 标题 + 副题 + 右侧工具条**，不许花活。
4. 同一行的面板等高等宽均分；面板间距恒 16px，块（面板组）间距 24～32px。
5. 阅读型页面（用量 / 日志）仍是纵向长卷——面板由上而下堆叠，不诞生小岛式布局。

### 原则三：强对比排版 —— 四层文本，层间至少差两项

一页之内只允许四层文字：**微标签 → 大标题 / 大数字 → 正文 → 注释**。相邻两层必须在「字族、字号、颜色」中至少两项上不同。微标签（eyebrow）是二期的签名元素：11px、大写、`0.14em` 字距、`500` 字重。

### 原则四：工具条语法 —— 控件上浮，内容纯净

每个页面头与面板头都收拢一条右对齐工具条：**分段控件 / pill（状态与摘要） + 图标按钮组 + 分隔**。控件不散落在内容里；面板工具条只保留与该面板数据直接相关的动作（切换序列、导出、设置）。

### 原则五：数据之色只给数据（一期铁律的强化）

- chrome（导航、按钮、边框、图标）永远黑白暖灰。
- 彩色只有两种身份：**图表矿物色**（赭石 / 靛青 / 苔绿 / 藤黄）与**对象标识点**（供应商 / 模型品牌色，复用现有 `--brand-*`）。
- 朱砂三铁律不变：只用于超预算 / 失败 / 已停用。
- 苔绿除图表外只开「在线」一口（呼吸点与存活状态）。

### 落地纪律（「企业级」的具体含义）

| 维度 | 允许值 |
| --- | --- |
| 颜色 | 仅 `theme.css` token，页面不出现字面色值 |
| 间距 | 4pt 阶梯：4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 |
| 字号 | 9 档（见 §4.2），其余免谈 |
| 圆角 | 4 / 8 / 12 / pill 四档 |
| 控件高度 | 28 / 32 / 40 三档 |
| 图标 | 16 / 20 / 24 三档（导航固定 20），stroke 1.5 |
| 动效 | 100 / 150 / 250ms 三档，必配 reduced-motion 降级 |
| 页面头 | 无一例外：微标签 + H1 + 副题句 + 工具条 |
| 面板 | 无一例外：卡头 + 内容；无头面板仅限行列表与空态 |

## 3. 颜色设计

### 3.1 纸、面、线

| token | 浅色（纸白） | 深色（夜纸） | 用途 |
| --- | --- | --- | --- |
| `--paper` | `#FBFAF8` | `#141311` | 应用画布；深色压深至近黑，保持暖调 |
| `--panel` | `#FEFDFB` | `#1A1916` | 面板面（卡纸叠纸） |
| `--panel-raised` | `#FFFFFF` | `#262320` | 模态、浮起层、密度更高的一级 |
| `--paper-deep` | `#F0ECE5` | `#201E1A` | 凹陷面：徽章底、行 hover、展开区 |
| `--line` | `#E2DCD2` | `#2A2722` | 发丝分隔线、下划线 |
| `--line-panel` | `#EAE5DC` | `#2E2A25` | 面板描边（比发丝线可见一档） |
| `--line-strong` | `#C4BEB2` | `#3A362F` | 强调线、选中规线 |
| `--line-control` | `#868074` | `#6E685E` | 表单控件边界（WCAG 1.4.11 ≥ 3:1，不变） |
| `--line-faint` | `rgb(222 217 208 / 60%)` | `rgb(255 255 255 / 7%)` | 装饰用最淡线 |

### 3.2 墨阶（四级，像墨渗在纸上）

| token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--ink` | `#1C1A17` | `#F2EEE7` | 标题、值、主文本 |
| `--ink-soft` | `#403B35` | `#D6D0C6` | 次级正文 |
| `--ink-muted` | `#6F6960` | `#A9A296` | 注脚、标签（**可读文本的最低档**） |
| `--ink-faint` | `#9A9389` | `#8A8378` | 仅图形与提示符号（图标、占位、装饰），不承载句子 |

> 纪律：任何需要「读」的字，最淡到 `--ink-muted`。`--ink-faint` 退出文本序列（一期遗留的 13px 灰文本随改造迁走）。

### 3.3 信号色（语义锁定，不变）

| token | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| `--ochre` | `#9B7854` | `#C29A6D` | 交互 / 选中 / 聚焦；深色提亮保证近黑上可见 |
| `--danger` | `#A65D55` | `#D0735F` | 朱砂：失败 / 已停用 / 超预算，绝不装饰 |
| `--live` | `#71806A` | `#96A78C` | 苔绿：仅「在线」呼吸点 |
| `--live-ring` / `--live-halo` | 苔绿 45% / 55% | 同 | 呼吸点光环 |
| `--surface-live` | `rgb(113 128 106 / 10%)` | `rgb(143 158 134 / 9%)` | 运行态的整行淡苔绿底 |

### 3.4 图表矿物色（深色提亮，浅色微调）

| token | 浅色 | 深色 | 说明 |
| --- | --- | --- | --- |
| `--chart-ochre` | `#9B7854` | `#C79C6C` | 序列一 |
| `--chart-indigo` | `#607087` | `#8FA3BE` | 序列二；深色明显提亮，向概念稿的「会发光的蓝」靠拢，但保持灰调 |
| `--chart-moss` | `#71806A` | `#95A68A` | 序列三 |
| `--chart-yellow` | `#A88C4E` | `#D5BB80` | 序列四；浅色略加深至图形对比 ≥ 3:1 |

- 面积渐隐**不新增 token**：`color-mix(in srgb, var(--chart-indigo) 26%, transparent)` 就地派生，顶部有浓度、底部归零。
- 深色下四色与面板的对比度全部 ≥ 6:1，浅色下 ≥ 3:1，满足图形元素标准。
- 热力墨阶（`--heat-*`）、品牌色（`--brand-*`）保持一期定义不动。

### 3.5 对象标识点（新）

为「对象」在列表与图表中提供一致的识别色点（8px 圆点，列表行与图例同色）：

1. 供应商 / 模型：命中品牌色 → `--brand-*`（一期已有识别逻辑）；未命中 → `--ink-faint` 中性点。
2. 虚拟密钥：不属于品牌对象，用 `--ink-faint` 中性点，不带彩色。
3. 状态点保持独立语义（live / stopped / error / cancelled），**与标识点不同形**：状态点有空心态与呼吸态，标识点实心静态。

### 3.6 其余 token 的调整

| token | 调整 |
| --- | --- |
| `--surface-sidebar` | 深色 `#161513`（与画布近同，靠 1px 线分隔，向概念稿靠拢）；浅色 `#F7F4EF` 不变 |
| `--surface-hover` / `-soft` / `-strong` | 值不变（6% / 5% / 8% 白）；但使用面扩展至面板头工具、列表行 |
| `--surface-active` | 深色改为 `#24221F`（选中导航项、分段选中） |
| `--tooltip-bg` | 深色 `rgb(38 35 32 / 98%)` |
| `--scrim` | 深色加深至 `rgb(0 0 0 / 65%)`（近黑画布上模态需要更重的压暗） |
| `--shadow-*` | 不变（深色下本就归零，浅色下沿用纸层阴影） |

## 4. 字体与尺寸

### 4.1 字体族（不引入 web 字体，栈不变）

| token | 栈 | 用途 |
| --- | --- | --- |
| `--font-serif` | Georgia → Noto Serif SC → 系统衬线回退 | **所有标题与大数字**：页面 H1、面板标题、指标值、甜甜圈中心、选中对象名 |
| `--font-sans` | Inter → Noto Sans SC → 系统无衬线 | 正文、标签、按钮、微标签、表格 |
| `--font-mono` | Cascadia Mono → Consolas 系 | ID、别名、请求号 |

血统保留点：概念稿的数值是粗壮无衬线，Lumen **坚持衬线数字**——这是账簿 DNA，也是与「仪表盘」的距离。

### 4.2 字阶（8 档 → 9 档）

| # | token | 值 | 族 | 字重 | 行高 | 字距 | 用途 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| 1 | `--text-display` | `clamp(1.75rem, 1.25rem + 1.9vw, 2.5rem)`（28→40） | serif | 600 | 1.08 | -0.01em | 页面 H1 |
| 2 | `--text-metric` | `clamp(1.625rem, 1.2rem + 1.5vw, 2.125rem)`（26→34） | serif | 600 | 1.02 | -0.01em | 指标大数 |
| 3 | `--text-section` | `clamp(1.0625rem, 1rem + 0.3vw, 1.25rem)`（17→20） | serif | 600 | 1.25 | 0 | 面板标题 |
| 4 | `--text-title` | `0.9375rem`（15） | sans | 600 | 1.3 | 0 | 分区题、表单组题 |
| 5 | `--text-body` | `clamp(0.9375rem, 0.9rem + 0.2vw, 1rem)`（15→16） | sans | 400 | 1.55 | 0 | 正文、摘要句 |
| 6 | `--text-small` | `0.8125rem`（13） | sans | 400 | 1.45 | 0 | 辅助、行内值 |
| 7 | `--text-caption` | `0.75rem`（12） | sans | 400 | 1.4 | 0 | 注脚、轴标签 |
| 8 | `--text-eyebrow` | `0.6875rem`（11） | sans | 500 | 1.2 | `0.14em` | 微标签（大写；中英混排时大写只作用于拉丁） |
| 9 | `--text-mono` | `0.8125rem`（13） | mono | 400 | 1.4 | 0 | ID、别名 |

与一期差异：新增 display 档（H1 从 30 涨到 40）；metric 微涨；body 上限从 18 收到 16（轻量化、提对比）；eyebrow 从 14 收到 11 并明确字距；新增独立 caption 档。

数字继承一期全部规则：`tabular-nums`、金额两位小数千分位、数量分级（万 / 亿 / 万亿）、中西文 1/4 空格（`86 次` / `1.2 万次` / `$38.6`）。

### 4.3 间距、圆角、描边

| 项 | 值 |
| --- | --- |
| 间距阶梯 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 48 |
| 面板内边距 | 20px（行列表类面板 16px） |
| 面板间距 | 16px |
| 面板组间距 | 24～32px |
| 页头 → 内容 | 24px |
| 列表行高 | 44px（单行）/ 56px（双行） |
| 圆角 | `4px` tag 等微元素 · `8px` 控件（按钮/输入/导航项/行 hover 面） · `12px` 面板与模态 · `pill` 胶囊与状态点 |
| 描边 | 1px 常规；2px 仅选中规线与 focus 环；focus-visible = 2px 赭石 outline offset 2px（不变） |
| 阴影 | 深色：无（层级靠面与线）；浅色：沿用 `--shadow-float`，模态升为 `--shadow-float` + 描边 |

圆角替换映射（改造用）：一期 `2px` → `4px`；`4px` → `8px`；`6px` → `12px`；pill 不变。「纸是裁切的」保留为语义纪律：**圆角不随内容浮动、不出现 16px+**。

```

│  ⚿ 虚拟密钥                │
│  ⌸ 上游提供商              │
│  ☰ 使用日志                │

│                            │

└────────────────────────────┘
```

- 宽 `clamp(12.5rem, 14vw, 17rem)`（200～272px），内距 20×16。
- 深色下侧栏与画布同族（`--surface-sidebar`），仅 1px 线分隔。
- 导航项高 36px、圆角 8、gap 4px；选中 = 面 + 600 字重 + `aria-current` 沿用。
- 不新增分组、不新增推广位；品牌区加一行微标签副题是本栏唯一新元素。

### 5.2 页面头（全站统一）

```
[微标签：USAGE LEDGER]                 [分段控件] [‹ 7月26日 ›] [☐ 今天] [⚙]
[大标题：今日总账（display 衬线）]
[副题：一句话摘要（body，ink-muted，单行截断）]
```

- 左侧三行自上而下，右侧工具条顶部对齐、垂直居中于 H1 行。
- 每页副题句必须存在（用量 = 现有 summary；路由/密钥/提供商 = 对象计数句；日志 = 筛选结果计数句；设置 = 一句话说明）。
- 与 WindowChrome 的关系：chrome 仍是独立 2.5rem 拖拽区，深色下与画布同底；页面头不与其合并。

### 5.3 面板（Panel）

```
┌─ 1px --line-panel · r12 · 底 --panel ────────────────┐
│ [◫] Acquisition spend          [工具条：pill 组 + 图标组] │  卡头（图标徽章 + 衬线 18~20）
│     Capital deployed by year · 7 years recorded        │  副题（caption · ink-muted）

└────────────────────────────────────────────────────────┘
```

- 卡头副题放标题下方（概念稿式），或标题右侧（数据摘要），同一面板内二选一。
- 面板工具条的 pill：28px 高、pill 圆角、1px 描边、内容 = 图标 14 + 数值 12.5 tabular + 分隔点 + 上下文（如 `15 vol · peak 2022`）。
- 面板禁止：渐变背景、彩色描边、体现装饰的角标、悬浮位移。

### 5.4 指标卡与微缩记录条（新组件）

```
┌─────────────────────────────┐
│ 本期花费                  ◷  │  微标签 + 右上角图标（16 ink-faint）
│ $1.24                       │  metric 衬线 34
│ 较上期 +12%                 │  small · ink-muted（比较行，沿用现有口径）
│ ▁▂▁▃▂▅▃▆▄▇▅█               │  微缩记录条：近 12 期，高 20
└─────────────────────────────┘
```

- 微条 = 该指标最近 12 期真实值（数据来自 `overview.series`），柱宽 4、间隙 3、底部对齐。
- 配色：默认墨阶（值越大越深）；当前期以 `--ochre` 强调；零值档只留一圈内描边（沿用热力零档逻辑）。
- 数据不足 12 期时按实际数量铺满、右对齐；无数据时不画装饰性占位。

### 5.5 按钮与图标按钮

- 主按钮：反色（深色白底墨字 / 浅色墨底纸字），用于「启动网关」「保存」「新建」。
- 次要按钮：描边 + 透明底，用于「重试」「导出」。
- text 按钮：无底无框，hover 面，仅用于「清除筛选」类轻动作。
- 危险动作：朱砂文字按钮 + 内联确认条（一期已定，沿用）；禁止红色实底大按钮。
- 图标按钮组：32px 方钮，组内 gap 2px，组间 8px 或一条 1px 竖分隔线；选中态 = 面 + 赭石图标。

### 5.6 表单控件

- 输入 / select / 日期：高 32（行内）与 40（模态）；圆角 8；边界 `--line-control`；focus 2px 赭石。
- 标签（field label）：微标签字阶或 13px `ink-muted`，置于控件上方 6px。
- 表单行距 16px；两个以上字段的编辑区用两列栅格（≥36rem 时）。

### 5.7 列表与表格

- 行式列表（日志 / 模型 / 别名 / 密钥）是二期的「表格替代品」：无表头、无斑马纹、行间 1px 发丝线。
- 行结构模板：`标识点 + 主文（14 ink） + 次文（12 caption ink-muted）` ← 左；`数值（13 tabular ink） + 副值（12 caption）` → 右。
- hover：`--surface-hover-soft` 面 + 8px 圆角；选中：面 + 2px 赭石左规线（仅登记簿使用）。
- 分组题：微标签（如日期题、分组名），带 `--line` 分隔，可选 sticky。

### 5.8 状态与徽记

| 语义 | 形态 |
| --- | --- |
| 在线（live） | 苔绿实心点 + 呼吸光环（仅启用态） |
| 已停止 | 空心墨点（`--ink-faint` 描边） |
| 失败 / 已停用 | 朱砂点 + 文字（必配文字） |
| 已取消 | 墨阶点 + 「已取消」+ 一行淡墨左规线（一期语义） |
| 用量存疑 | 墨阶点 + 「用量未上报 / 不完整」 |
| 品牌对象 | 品牌 LOGO / 标识点（静态实心 8px） |

所有状态继续遵守「颜色不单独承载信息」。

### 5.9 模态与浮层

- 模态：r12、`--panel-raised` 底、浅色加极淡阴影、深色纯描边；scrim 深色加深到 65%。
- 下拉 / 日历 / tooltip：随圆角与面体系升级（popover 底用 `--panel-raised` + 1px 线）。
- 全站唯一图表浮层仍只有 Tooltip。

### 5.10 图表规格（概念稿增量）

| 部件 | 规格 |
| --- | --- |
| 折线 | 直线段连接（linear，不做样条）；线宽 1.75px；多序列 = 序列色 100% + 40% alpha，或前两个矿物色 |
| 面积 | 单色垂直渐隐：线色 26% → 0（`color-mix` 派生）；同一图至多两条面积，其余仅线 |
| 端点聚焦（新） | 最后数据点：5px 实心圆（线色）+ 2px 面板色描边环；自该点垂直接一条 1px dashed（线色 35%）到 x 轴 |
| 轴 | y 轴 3～5 档、x 轴均匀刻度；12px caption、tabular、`--ink-muted`；保留 1px 基线（plot 底边） |
| 无脚手架 | 网格线、图例块、轴框维持「无」；序列身份靠直接标注 + tooltip |
| 环形图 | 2px 纸白缝保留；选中扇区外扩 2px；中心 = 衬线 metric + caption 双行（如模型名 + 占比） |
| 柱状 | 柱顶 2px 圆角、间隙 2px、贴基线；当前档赭石，其余墨阶 |
| 热力 | 一期墨阶不变（含零档内描边、图例刻度） |
| 边界淡出 | 保留语义（数据未走完 / 到此为止），仍只许单色 alpha 渐隐、禁彩色渐变与投影 |
| Tooltip | 沿用；样式升级为 r8 + 1px 线 + `--tooltip-bg` |

### 5.11 空 / 错 / 载态

- 加载：`LoadingLines` 沿用（行骨架 + 发丝线），骨架色 `--line`，行数 = 预期内容规模。
- 空态（面板内）：24px 图标（`--ink-faint`） + 一句话（body，`--ink-muted`） + 可选次要按钮；不画插画、不写鸡汤。
- 错误：朱砂点 + 一句话 + 「重试」次要按钮；模块级错误包在该面板内，不炸全页。
- 部分失败：面板级朱砂标记 + 其余面板照常呈现（磁盘 / 统计可降级的场景）。

## 7. 动效与可达性

### 7.1 动效

- 三档保留：100ms（hover / 颜色）、150ms（展开、分段切换）、250ms（模态、最大动作）。
- 页面切换入场保留（150ms 淡入 + 0.25rem 上移）。面板不加入场动画——静态是气质。
- 呼吸点、metric 数字滚动、图表入场动画（一期已有：`metricAnimation` / `charts-motion`）保留，仅当 `prefers-reduced-motion` 时全部降级。

### 7.2 可达性清单

- 正文文本对比 ≥ 4.5:1（墨阶四级中 `--ink-faint` 退出文本序列后即可确保）；大字与图形 ≥ 3:1。
- focus-visible：2px 赭石 outline、offset 2px（全站统一）。
- 颜色不单独承载信息：状态必配文字；标识点只做识别、不传语义。
- 键盘：分段控件、面板工具条图标按钮、行展开均须可达；沿用一期焦点管理。

## 9. 实施映射（后续施工参考）

### 9.1 Token 变更

- `theme.css`：按 §3 全表替换 / 新增（`--panel`、`--panel-raised`、`--line-panel`、`--text-eyebrow` 等新增；`--paper`/`--ink-*`/`--line*`/`--ochre`/`--danger`/`--live`/`--chart-*` 改值）。
- `base.css`：字阶 token 按 §4.2 替换；`--tracking-label` 收敛为 `0.14em` 并限定为微标签专用（分区题等不再引用）。
- `layout.css`：`--sidebar-width`、`--page-gutter-x/y` 按 §6.0 调整；可增 `--panel-gap: 1rem`、`--panel-pad: 1.25rem` 语义 token。
- 圆角在 `base.css` 增 `--radius-tag/-control/-panel` 三 token（pill 用现约定），全站替换字面量。

### 9.2 建议顺序（每步可独立验收）

1. **Token 与排版**：theme / layout / base 三文件 + 对比度抽查（两主题）。
2. **壳与侧栏**：Sidebar、WindowChrome 底色、页面头结构（所有页面共用）。
3. **用量页**：指标卡 + 微条、吞吐 / 成本 / 洞察重排、图表新皮肤。
4. **操作型三页**：路由 / 密钥 / 提供商面板化（登记簿 + 书写台）。
5. **日志与设置**：流水面板、口径分段控件、设置分区卡。
6. **收尾**：空 / 错 / 载态巡检、深色截图核对、reduced-motion 巡检。

### 9.3 验收口径（每阶段）

- `pnpm test` / `pnpm build` / `cargo test` 不回归；DOM 类名序列不变（样式改造），新增组件另行登记。
- 两主题各截三张图（用量 / 路由 / 日志）人工目视：面板等高、间距 4pt 阶梯、无字面色值、数字全 tabular。
- 对比度抽查：正文四墨阶、图表四色、状态点（浅深各一遍）。
