# Lumen 后端接口文档（前端使用）

> 面向前端的 Rust 后端契约说明。所有 IPC 通过 `@tauri-apps/api/core` 的 `invoke` 调用，事件通过 `@tauri-apps/api/event` 的 `listen` 订阅。命令名与参数保持 Rust 侧原样。

## 约定

- **DTO 命名**：Rust 侧统一 `#[serde(rename_all = "camelCase")]`，前端拿到的是 camelCase 字段。
- **时间**：一律 RFC3339 字符串（UTC，如 `2026-09-10T11:08:05+00:00`）。
- **金额**：CNY，`number`，网关按「每百万 token」单价计算，保留 6 位小数。
- **端口 / 地址**：默认 `127.0.0.1:8787`，仅绑回环；网关默认关闭，由前端显式启停。
- **错误**：命令返回 `Result<T, AppError>`，失败时 Promise reject，值为字符串（`AppError` 序列化为字符串），直接用 `String(err)` 展示即可。
- **浏览器回退**：非 Tauri 环境（`pnpm dev`）应走 mock；本项目已在 `src/services/gateway.ts` 用 `isTauriRuntime(window)` 做守卫，新增接口沿用同一模式。

## 1. 类型定义（TypeScript）

```ts
// ---- 网关状态 ----
export type GatewayStatus = {
  running: boolean;
  port: number;
  baseUrl: string;      // http://127.0.0.1:<port>
  error: string | null; // 启动失败时携带原因
};

// ---- 上游提供商 ----
export type AuthScheme = "bearer" | "x-api-key";
export type Protocol = "openai" | "anthropic";

export type Provider = {
  id: string;
  name: string;
  baseUrl: string;                 // 需含版本段，如 https://api.openai.com/v1
  apiKey: string;
  authScheme: AuthScheme;
  protocol: Protocol;
  extraHeaders: Record<string, string>;
  enabled: boolean;
  createdAt: string;
};

export type ProviderInput = {
  id?: string | null;              // 传 id 为更新，否则新增
  name: string;
  baseUrl: string;
  apiKey?: string;
  authScheme?: AuthScheme;         // 默认 "bearer"
  protocol?: Protocol;             // 默认 "openai"
  extraHeaders?: Record<string, string>;
  enabled?: boolean;               // 默认 true
};

// ---- 上游模型 ----
export type UpstreamModel = {
  id: string;
  providerId: string;
  modelId: string;                 // 实际发给上游的 model 名
  displayName: string;
  inputPrice: number;              // 每百万 token
  outputPrice: number;             // 每百万 token
  enabled: boolean;
};

export type UpstreamModelInput = {
  id?: string | null;
  providerId: string;
  modelId: string;
  displayName: string;
  inputPrice?: number;
  outputPrice?: number;
  enabled?: boolean;
};

// ---- 模型路由 ----
export type Route = {
  id: string;
  alias: string;                   // 对外暴露的 model 名（唯一）
  displayName: string;
  enabled: boolean;
  createdAt: string;
};

export type RouteTarget = {
  id: string;
  routeId: string;
  upstreamModelId: string;
  priority: number;                // 越小越优先；MVP 只取第一个 enabled
  enabled: boolean;
};

// list_routes_cmd 返回：Route 字段被 flatten，外加 targets
export type RouteWithTargets = Route & { targets: RouteTarget[] };

export type RouteTargetInput = {
  upstreamModelId: string;
  priority?: number;               // 默认 0
  enabled?: boolean;               // 默认 true
};

export type RouteInput = {
  id?: string | null;
  alias: string;
  displayName: string;
  enabled?: boolean;
  targets: RouteTargetInput[];     // save 时整体替换
};

// ---- 虚拟密钥 ----
export type VirtualKey = {
  id: string;
  key: string;
  name: string;
  enabled: boolean;
  createdAt: string;
};

export type VirtualKeyInput = {
  id?: string | null;
  key?: string | null;             // 留空则后端自动生成 sk-lumen-<uuid>
  name: string;
  enabled?: boolean;
};

// ---- 使用日志 ----
export type RequestLog = {
  id: string;
  occurredAt: string;
  endpoint: string;                // /v1/chat/completions | /v1/messages
  method: string;
  routeAlias: string | null;
  routeId: string | null;
  upstreamModelId: string | null;
  upstreamModelName: string | null;
  providerId: string | null;
  virtualKeyId: string | null;
  kind: string;                    // 目前恒为 "chat"
  inputTokens: number;
  outputTokens: number;
  totalTokens: number;
  cost: number;
  status: string;                  // "success" | "error"
  httpStatus: number | null;
  latencyMs: number | null;
  errorMessage: string | null;
  isStream: boolean;
};

export type LogFilter = {
  routeAlias?: string | null;
  status?: string | null;
  query?: string | null;           // 模糊匹配 别名/上游模型/类型/token
  limit?: number | null;           // 默认 200，范围 1..1000
  offset?: number | null;          // 默认 0
};

// ---- 用量统计 ----
export type PeriodKey = "day" | "week" | "month";

export type Metric = {
  label: string;                   // 调用次数 / 输入 Tokens / 输出 Tokens / 总花费
  value: string;                   // 已格式化： "86 次" / "48.2 万" / "¥ 4.82"
  comparison: string;              // "较昨天同期 +4%" 或 "暂无同期数据"
};

export type ChartTone = "ochre" | "indigo" | "moss" | "yellow";

export type ModelCost = {
  name: string;                    // 上游模型展示名，超出 4 类合并为 "其他"
  cost: number;
  tone: ChartTone;
};

export type UsageSeries = {
  current: string;                 // 如 "今天"
  previous: string;                // 如 "昨天同期"
  currentValues: number[];         // 累计 token（单位：万），前端自行差分/重采样
  previousValues: number[];
};

export type UsageOverview = {
  periodKey: PeriodKey;
  heading: string;                 // "今日总账" / "本周总账" / "9月总账"
  summaryLead: string;
  summaryTail: string;
  metrics: Metric[];               // 固定 4 条，顺序：次数/输入/输出/花费
  totalCost: number;
  axisLabels: string[];
  yAxisMax: number;                // 已做 nice 取整
  series: UsageSeries;
  modelCosts: ModelCost[];
};

// ---- 设置 ----
export type Settings = {
  port: number;                    // 1024..65535
};
```

## 2. 命令一览（21 个）

调用形式：`invoke<T>("<命令名>", { ...参数 })`。

### 网关生命周期

| 命令 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `gateway_status` | — | `GatewayStatus` | 当前运行状态与地址 |
| `start_gateway` | — | `GatewayStatus` | 绑定回环端口并启动；端口占用会 reject，同时推送失败状态事件 |
| `stop_gateway` | — | `GatewayStatus` | 优雅关闭并释放端口 |

```ts
await invoke<GatewayStatus>("start_gateway");
await invoke<GatewayStatus>("stop_gateway");
const status = await invoke<GatewayStatus>("gateway_status");
```

### 上游提供商

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_providers_cmd` | — | `Provider[]` |
| `save_provider_cmd` | `{ input: ProviderInput }` | `Provider` |
| `delete_provider_cmd` | `{ id: string }` | `void` |

### 上游模型

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_upstream_models_cmd` | — | `UpstreamModel[]` |
| `save_upstream_model_cmd` | `{ input: UpstreamModelInput }` | `UpstreamModel` |
| `delete_upstream_model_cmd` | `{ id: string }` | `void` |

### 模型路由

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_routes_cmd` | — | `RouteWithTargets[]` |
| `save_route_cmd` | `{ input: RouteInput }` | `RouteWithTargets` |
| `delete_route_cmd` | `{ id: string }` | `void` |

> `alias` 唯一；`save_route_cmd` 会用 `targets` 整体替换该路由的目标列表。

### 虚拟密钥

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_virtual_keys_cmd` | — | `VirtualKey[]` |
| `save_virtual_key_cmd` | `{ input: VirtualKeyInput }` | `VirtualKey` |
| `delete_virtual_key_cmd` | `{ id: string }` | `void` |

### 使用日志

| 命令 | 参数 | 返回 |
|---|---|---|
| `list_logs_cmd` | `{ filter?: LogFilter }` | `RequestLog[]`（按时间倒序） |
| `count_logs_cmd` | `{ filter?: LogFilter }` | `number` |
| `list_log_aliases_cmd` | — | `string[]`（筛选下拉用） |

### 用量统计

| 命令 | 参数 | 返回 |
|---|---|---|
| `query_usage_overview_cmd` | `{ period: PeriodKey; anchor?: string \| null }` | `UsageOverview` |

- `anchor`：RFC3339 时间串，用于查询任意历史周期；省略则取当前时间。
- `series` 为**累计值**（单位：万 token），与 `src/features/usage/usageVisualData.ts` 的 `cumulativeToDistribution` 配套使用。
- `day` 桶为 24 个小时点，`week` 为 7 天，`month` 为当月天数；前端可 `resampleSeries` 到可视点数。
- `modelCosts` 至多 4 条，末位为「其他」，`tone` 按排名映射到矿物颜料 token。

```ts
const overview = await invoke<UsageOverview>("query_usage_overview_cmd", {
  period: "week",
  anchor: new Date().toISOString(),
});
```

### 设置

| 命令 | 参数 | 返回 | 说明 |
|---|---|---|---|
| `get_settings_cmd` | — | `Settings` | |
| `save_settings_cmd` | `{ input: Settings }` | `Settings` | 网关运行中会 reject（需先停止） |

## 3. 事件

前端在页面挂载时 `listen`，卸载时调用返回的 unlisten。

| 事件名 | 载荷 | 触发时机 |
|---|---|---|
| `gateway://status` | `GatewayStatus` | 启动 / 停止 / 启动失败 |
| `gateway://log` | `RequestLog` | 每次请求落库后（含流式结束、错误、404） |

```ts
import { listen } from "@tauri-apps/api/event";

const unlisten = await listen<RequestLog>("gateway://log", (event) => {
  appendRow(event.payload);
});
```

> 统计页可在收到 `gateway://log` 后做防抖，再调用 `query_usage_overview_cmd` 刷新总账，避免高频聚合。

## 4. HTTP 网关端点（供 Agent 客户端，非前端 IPC）

网关启动后监听 `http://127.0.0.1:<port>`：

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/health` | 健康检查 |
| GET | `/v1/models` | 列出**别名**（不暴露上游模型名） |
| POST | `/v1/chat/completions` | OpenAI 兼容；请求 `model` 填别名 |
| POST | `/v1/messages` | Anthropic 兼容直通；用于 Claude Code 等 |

转发规则：`model` 别名 →（路由目标，取 priority 最小且 enabled）→ 上游模型；替换 `model` 后按 provider 的 `protocol` / `authScheme` / `extraHeaders` 注入请求头，透传响应与 SSE。

## 5. 前端接入建议

- 新增 IPC 封装放 `src/services/`，统一 `invoke` + `isTauriRuntime` 回退。
- 用量页 `UsagePage` 可用 `query_usage_overview_cmd` 替换 `UsagePeriod` mock；账本明细用 `list_logs_cmd` 替换 `buildMockLedgerEntries`。
- 纯逻辑模块（`chartGeometry` / `trendInteraction` / `usageVisualData`）无需改动，继续消费后端返回的数据形状。
